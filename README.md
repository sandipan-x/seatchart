# SeatChart

Plan your wedding seating chart free online. Drag guests onto tables, watch capacities fill, and track every unassigned guest until the chart is done.

## Features
- Drag-and-drop guest assignment between the unassigned pool and named tables
- Per-table guest counts with capacity warnings when a table is overfilled
- Unassigned-guest tracker so you always know exactly who still needs a seat
